# Python Basics — Variables, Loops, Functions

## Variables

```python
x = 5
name = "hello"
is_valid = True
```

## Lists

```python
items = [1, 2, 3]
items.append(4)
for item in items:
    print(item)
```

## Functions

```python
def greet(name: str) -> str:
    return f"Hello, {name}"
```

## Dicts

```python
config = {"key": "value"}
config.get("key", "default")
```
